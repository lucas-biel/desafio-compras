## Descrição do projeto 

<p align="justify">
  Este projeto tem como objetivo a prática do conteúdo aprendido durante o curso, utilizando a linguagem Java, através do desenvolvimento de um desafio proposto durante o curso de Java: trabalhando com listas e coleções de dados, da Alura.
  O desafio consiste em desenvolver um algoritmo que receba dados do usuário e execute ações a partir destes dados.
</p>

## Funcionalidade

:heavy_check_mark: Inserir produtos em uma lista de compra.

:heavy_check_mark: Exibir os produtos que foram comprados na tela.

## Como rodar a aplicação :arrow_forward:

No terminal, clone o projeto: 

```
git clone https://github.com/lucas-biel/desafio-compras.git
```

Feito isso, execute o arquivo `Main.java`, que se encontra na pasta `src`.
